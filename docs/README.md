# Название: Конференции.РФ

Портал "Конференция.РФ" - создана для бронирования помещений и управления заявками на проведение конференций, система создана для организаторов мероприятий, которым нужно быстро найти и забронировать аудиторию.

> # Стек:
>
> **Backend:** Node.js, Express; **База данных:** SQLite; **Шаблонизатор:** EJS; **Frontend:** HTML,Bootstrap,CSS.

## Установка

> npm install

## Запуск

> npm start → http://localhost:3000

## Роли

- Пользователь: регистрация, вход, просмотр помещений, создание заявки, просмотр своих заявок, просмотр деталей, оставление отзыва после «Завершено».
- Админ: всё, что может пользователь, плюс просмотр всех заявок, смена статуса, просмотр данных пользователей в заявках.

## Структура

> **Список папок и файлов с кратким описанием:** server.js — маршруты, db.js — схема и классы, views/ — шаблоны, public/ — статика, docs/ — документация.

## Маршруты

> **Таблица:** метод, URL, доступ, что делает. Маршруты из фактического кода + маршруты из лекции 12 (GET /request/:id, POST /review/:id).
> **Безопасность:** пароли хэшируются через bcryptjs, сессии на 2 часа + 20 минут бездействия, cookie с httpOnly и sameSite: 'lax', мидлвары requireAuth и requireAdmin.
